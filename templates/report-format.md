# Report format

What a scan report looks like. Send it only when there's something to report.

```
<N> new match(es) today. Best first.

Follow-ups
- ⭐ <Company> <Role>: applied <date>, follow-up due today. <one suggested action>
- <Company> <Role>: marked Stale/No response (applied <date>, no reply in 45+ days).

1. **<Title>, <Company>** (<City, ST>, <on-site/hybrid/remote>). Score <N>/10
   Posted <date> · <$range or "salary not listed"> · <clearance needed, only if relevant>
   Fits: <one line>
   Gap: <one line>
   <link to the posting>

2. ...

<K> wildcards (5-6) added to "New matches to review."
Suggested for watchlist: <Company>, <Company>

Next step: <one recommendation, e.g. "I'd apply to #1. Want me to start the resume?">
```

Rules:
- Best match first.
- One honest gap per hit.
- A link to the posting itself, not a search page.
- Optional extra line, only when the posting says so: tuition help, development program, flexible hours.
- No padding, no hype, no repeats of jobs already reported unless something changed.
