# Changelog

## v1.0.0 (2026-11-13)

First public release.

- README skills table and instructions for importing the skills into a bot.
- Guided setup script (`SETUP.md`) an AI agent follows to onboard a beginner.
- Ten skills: setup interview, Notion tracker setup, job scan, scoring, report, resume tailoring, apply, tracker updates and follow-ups, recruiter message drafts, scan routine setup.
- Shared guardrails every skill follows.
- Safety rules: per-posting permission before any submission, and personal info and logins stored in the vault.
- Templates: candidate profile, `persona.md` (bot persona), `routines.md` (scan prompt and cron), company watchlist, and report format.
- Worked example with a fictional candidate.
- Notes for using the package with agents other than Grok Bot.
