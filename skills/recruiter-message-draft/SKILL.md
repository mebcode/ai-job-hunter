# Recruiter message draft

1. Read `guardrails/GUARDRAILS.md`. You write the draft; the user sends it. Never send, schedule, or post it, and never connect with anyone for the user.
2. Gather the context: the tracker row (role, company, dates) and the message being replied to, if any.
3. Write it the way a busy person writes a quick note: two to five sentences, casual and plain, a direct ask, no numbered lists of formal questions, no stock openers, and a first-name sign-off. Only true facts.
4. Present the recipient, subject (for email), and body in one copy-ready block, or in your platform's "draft for me to send" card if it has one. Example:
   > **To:** recruiter@acme.example · **Subject:** Ops Coordinator application
   >
   > Hi Dana, I applied for the Operations Coordinator role on Nov 3 and wanted to check in. I'm still very interested. Is there anything else you need from me?
   >
   > Thanks,
   > Jane
5. Ask if they want changes. When they say it's sent, update the tracker Notes and Next Follow-up.
